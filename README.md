# ✏️ Веб-выделитель (Web Highlighter)

> Chrome-расширение для подсветки важных фрагментов текста на любых веб-страницах. Как маркер в учебнике, только для интернета.

## Возможности

- 🖍 **Подсветка текста** — выделите текст на любой странице, нажмите «Сохранить» — текст станет жёлтым
- 💾 **Автосохранение** — все выделения сохраняются в `chrome.storage.local` вместе с URL, заголовком страницы и датой
- 📋 **Список выделений** — popup-окно показывает все сохранённые выделения, отсортированные по дате
- 🔗 **Быстрый переход** — клик по выделению в popup открывает страницу-источник в новой вкладке
- 🗑 **Удаление** — каждое выделение можно удалить из списка
- 🔄 **Восстановление подсветки** — при повторном посещении страницы ранее выделенные фрагменты снова подсвечиваются
- 📥 **Экспорт в Markdown** — выгрузите все выделения в Markdown-файл
- 🎯 **Manifest V3** — современный стандарт расширений Chrome

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/web-highlighter-extension.git
cd web-highlighter-extension
```

### 2. Откройте страницу расширений Chrome

Откройте в браузере Chrome (или любом Chromium-based браузере):

```
chrome://extensions/
```

### 3. Включите Developer mode

Переключатель **Developer mode** (Режим разработчика) в правом верхнем углу → включить.

### 4. Загрузите расширение

Нажмите **Load unpacked** (Загрузить распакованное) и выберите папку `web-highlighter-extension`.

### 5. Готово!

Иконка расширения ✏️ появится в панели инструментов Chrome.

## Использование

1. **Выделите текст** на любой веб-странице (Wikipedia, статья, документация)
2. **Нажмите «✏️ Сохранить»** — появится жёлтая подсветка и уведомление
3. **Кликните на иконку расширения** ✏️ в панели Chrome, чтобы увидеть все сохранённые выделения
4. **Кликните по выделению** в списке, чтобы открыть страницу-источник
5. **Нажмите «Удалить»**, чтобы убрать выделение
6. **Нажмите «Экспорт в Markdown»**, чтобы скачать все выделения в формате Markdown

## Структура проекта

```
web-highlighter-extension/
├── manifest.json          # Конфигурация расширения (Manifest V3)
├── icons/                 # Иконки расширения
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
├── content/               # Content script (работает на страницах)
│   ├── content.js         # Логика выделения и сохранения
│   └── content.css        # Стили для кнопки и подсветки
├── popup/                 # Popup-окно расширения
│   ├── popup.html         # HTML-структура popup
│   ├── popup.css          # Стили popup
│   └── popup.js           # Логика отображения и управления
└── README.md              # Этот файл
```

## Технические детали

- **Manifest V3** — современный стандарт расширений Chrome
- **Content Script** — инжектится на все страницы (`<all_urls>`), отслеживает выделение текста
- **chrome.storage.local** — для хранения выделений (не `localStorage`)
- **Чистый HTML/CSS/JS** — без фреймворков
